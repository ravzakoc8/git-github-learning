
# Git Nedir?

## Tanım
Git, bir versiyon kontrol sistemidir.
Yazılım projelerindeki dosyalarda yapılan
değişiklikleri takip etmemizi sağlar.

## Git'i Neden Kullanırız?

- Dosyalardaki değişiklikleri takip etmek için.
- Projenin önceki sürümlerine dönebilmek için.
- Birden fazla geliştiriciyle birlikte çalışabilmek için.
- Projenin farklı sürümlerini yönetebilmek için.

## Önemli Kavramlar

- Repository (Depo): Git tarafından takip edilen proje.
- Commit (Kayıt): Yapılan değişikliklerin kaydedilmiş hâli.
- Branch (Dal): Ana projeden bağımsız olarak geliştirme yapmamızı sağlayan dal.

## Benim Anladığım

Git, projelerimde yaptığım değişiklikleri
takip etmemi sağlar. Bir hata yaparsam
önceki sürümleri inceleyebilir ve
gerekirse eski hâline dönebilirim.

## Yaptığım Uygulama

Git'i bilgisayarıma kurdum ve sürümünü
kontrol ettim.

## Kullandığım Komut

```bash
git --version
```
